Video Creator Prototype - 빠른 사용법
=====================================

Cursor 에이전트 채팅에 영상 내용을 쓰면, 에이전트가 장면 이미지를 만들고
MP4 파일까지 완성해 주는 도구입니다. 별도 로그인은 없습니다.
(Cursor와 제휴하지 않은 비공식 도구입니다.)

준비물: Cursor(이미지 생성이 되는 플랜), Git, Python 3.8 이상, ffmpeg
아래 명령은 Windows의 Git Bash 기준입니다. macOS는 [mac] 표시를 참고하세요.


1. 내려받기
-----------
  git clone -b prototype https://github.com/KORBrianLee/Video-Creator-Prototype.git
  cd Video-Creator-Prototype


2. Python 확인 (없으면 설치)
---------------------------
  python --version

  -> "Python 3.x.x"가 나오면 통과.
  -> 안 나오면 설치 후 Git Bash를 새로 엽니다.
     winget install --id Python.Python.3.12 -e
     [mac] brew install python


3. ffmpeg 설치
--------------
  winget install --id Gyan.FFmpeg -e
  [mac] brew install ffmpeg

  설치 후 Git Bash를 닫고 새로 연 다음 확인합니다.
  ffmpeg -version


4. 첫 실행 설정 (설정 창이 뜹니다)
----------------------------------
  cd Video-Creator-Prototype
  python setup.py
  (Windows에서는 install.bat 더블클릭도 같습니다)

  창에서 고르는 것
    - 렌더링 방식: 자동(GPU 우선) / GPU만 / CPU만
    - 인코더: 이 PC에서 동작하는 것만 나옵니다
    - 저장 위치: 기본 D:\VideoCreator (영상 파일은 C 드라이브를 피하세요)
    - 기본 화질, 프레임 보간 방식
    - "Cursor 스킬 설치" 체크 (모든 프로젝트에서 쓰려면 체크)
  잘 모르겠으면 [기본값으로 시작]을 누르세요. 나중에 python setup.py로 다시 바꿀 수 있습니다.
  (Linux에서 창이 안 뜨면 python3-tk를 설치하거나, 터미널 질문에 답하세요.)


5. 데모로 동작 확인
-------------------
  python video_render.py video-projects/demo/storyboard.json

  -> 마지막 줄에 "Done: D:\VideoCreator\renders\video-creator-demo.mp4"가 나오면 성공.
  -> 영상 열어 보기:
     start D:/VideoCreator/renders/video-creator-demo.mp4
     [mac] open ~/VideoCreator/renders/video-creator-demo.mp4


6. Cursor에서 쓰기
------------------
  Cursor에서 File -> Open Folder 로 Video-Creator-Prototype 폴더를 엽니다.
  에이전트 채팅에 이렇게 요청합니다.

    예) 제주 바다 일출 20초 영상 만들어 줘, 16:9
    예) 신제품 커피 머신 소개 15초 세로 영상, 자막은 한국어로

  에이전트가 순서대로 처리합니다.
    장면 이미지 생성 -> storyboard.json 작성 -> MP4 렌더링
  완성 파일: renders/<영상이름>.mp4

  사람·장비가 움직여야 하는 장면 (예: 작업자가 들어오고 차량이 멈춤)
    Cursor에는 영상 생성 모델이 없어서, 고정 카메라로 동작 순서대로
    키프레임 12~16장을 만들고, 그 사이를 30fps로 보간해 부드럽게 잇습니다.
    예) 작업자가 선로 옆 위험영역에 들어서자 기관차가 멈추는 장면을
        고정 카메라 키프레임 16장으로 만들어 줘
    -> 연속 동작이 아니라 키프레임 사이를 보간한 영상입니다.
    -> 보간 방식: GPU 크로스페이드(약 20초) / 움직임 보간(약 5분, 더 자연스러움)
    -> 발 위치처럼 세밀한 위치는 이미지 생성기가 정확히 따르지 않을 수 있습니다.
       "카메라에서 12m, 왼쪽 레일 바로 옆 자갈 위"처럼 구체적으로 쓰세요.


7. 추천 모델과 생각 단계
------------------------
  추천: Claude Sonnet 5.5 + 생각 단계 "보통"

  화질 자체는 채팅 모델이 아니라 Cursor 내장 이미지 생성이 결정합니다.
  채팅 모델은 이미지 프롬프트를 얼마나 정확히 쓰는지,
  잘못 나온 이미지를 알아채고 다시 만드는지를 좌우합니다.

  - 사실감 + 절약: Claude Sonnet 5.5, 보통
  - 같은 형식을 대량으로 찍을 때: Composer 2.5 fast, 낮음
  - 높음/최대 생각 단계, Opus급 모델은 결과가 거의 같고 비용만 늘어납니다.

  사용량 아끼는 법
  - 영상 작업은 새 채팅에서 하세요. 긴 대화는 메시지마다 앞 내용을 다시 처리합니다.
  - 이미지 개수가 사용량을 가장 많이 씁니다. "장면 5개로", "키프레임 3장으로"처럼 정하세요.
  - 수정은 "이미지는 다시 만들지 말고 자막만 고쳐 줘"처럼 범위를 좁히세요.
  - 같은 장소의 영상은 처음 만든 이미지를 참조로 재사용하라고 요청하세요.


8. (선택) 다른 프로젝트에서도 쓰기
---------------------------------
  4번 설정 창에서 "Cursor 스킬 설치"를 체크했다면 이미 설치되었습니다.
  나중에 하려면: python setup.py 를 다시 실행해서 체크하거나

  cp -r .cursor/skills/cursor-video ~/.cursor/skills/

  Cursor를 다시 시작하면 어느 폴더에서든 동작합니다.
  Video-Creator-Prototype 폴더는 지우지 마세요.
  에이전트가 video_render.py 위치를 물으면 이 폴더 경로를 알려 주면 됩니다.


문제 해결
---------
  - "python: command not found" 또는 Microsoft Store가 열림
      -> python 대신 py -3 를 써 보세요.
         예) py -3 video_render.py video-projects/demo/storyboard.json

  - "ffmpeg not found"
      -> Git Bash를 새로 열어 보세요. 그래도 안 되면 PC를 재시작합니다.

  - 에이전트 채팅에서 터미널 명령이 전부 실패함 (TEMP 경로 오류 등)
      -> Git Bash에서 아래를 실행한 뒤 Cursor를 완전히 껐다 켭니다.
         setx TEMP "$LOCALAPPDATA\Temp"; setx TMP "$LOCALAPPDATA\Temp"
      -> 그래도 안 되면 에이전트가 브라우저 렌더러(studio.html) 사용법을 안내합니다.

  - "Error: images not found"
      -> 에이전트에게 "이미지 경로 고쳐서 다시 렌더링해 줘"라고 요청하세요.

  - 저장 위치나 GPU/CPU 선택을 바꾸고 싶음
      -> python setup.py 를 다시 실행합니다. 현재 설정: python vc_config.py --show
