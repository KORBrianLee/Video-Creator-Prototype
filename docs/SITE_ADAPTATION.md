# 중장비·작업자 현장용 변경 — 0.6.0

중장비와 근처 작업자가 함께 있는 장면을 위한 프롬프트·실사 참고 자료·연속 생성 경로를 추가했다. **현재는 초안 시험용이다. 모델 가중치 사전학습/미세조정은 실행하지 않았고, SORA2급 자연스러운 현장 영상은 달성하지 못했다.** 해변의 기존 검증 성공을 현장 품질 성공으로 대신하지 않는다. 실제 현장 품질 상태는 `video_doctor.construction`과 `quality/construction-cpu.json`에서 별도로 확인한다.

## 준비한 것

- 굴착기 신호/버킷 동작, 로더 유도, 덤프 하역, 지게차 유도, 크레인 인양, 롤러 작업, 실사 레일 현장 등 8개 프롬프트. `video_site_presets`로 이름만 읽고 `site_template` 한 개를 보내면 로컬에서 요청을 확장한다. 임의 대본을 템플릿으로 바꾸지 않으며, 다른 동작은 Cursor가 짧은 영문 장면으로 전달한다.
- 정지 배치용 `first_frame_prompt`와 움직임용 `prompt`를 분리했다. 같은 굴착기의 신호/버킷 동작은 시작 이미지 캐시를 공유할 수 있다. 참조 이미지·프롬프트·seed·정밀도·길이·계산 코드가 달라지면 영향받는 캐시를 구분한다.
- **실제 현장 영상 3개, 4초 참고 구간 9개**, 원본·SHA256·저작자·라이선스·변경 내역. 저장 위치는 `D:\CursorVideoLocal\datasets\construction-v1`. 참고 구간은 원본의 프레임율을 정규화한 자료이며 모델이 새로 만든 영상으로 표시하지 않는다.
- 모델의 텍스트 조건을 미리 계산하는 `tools/warm_site_prompts.py`. 이 파일이 만드는 것은 재사용 가능한 임베딩이며 학습된 새 가중치가 아니다. 실제 준비 상태는 데이터 폴더의 `conditioning/manifest.json`이다.
- `continuous=true`에서 하나의 생성 호출이 과거 잠재 프레임을 이어받는다. 2/4/8/10/15초 요청은 Neo에서 24fps 49/97/193/241/361개의 실제 생성 프레임이다(15초 = 잠재 프레임 46개, 모델 한계 200 이내). 인과 VAE의 `8n+1` 조건 때문에 파일은 각각 2.0417/4.0417/8.0417/10.0417/15.0417초다. NVIDIA 장시간 모델(SkyReels)은 10/15초에 학습 정렬값 257/377프레임을 쓴다. 복수 장면을 넣으면 거절하며 컷 연결·반복·보간·재생속도 변경으로 길이를 만들지 않는다. **8초 현장 품질은 미검증**이다.
- `quality`는 원본 BF16 행렬을 D에서 매핑한 뒤 현재 행렬 계산만 FP32로 변환한다. `preview`는 채널별 INT8이다. 두 경로 모두 CPU 4스레드, 추론 상주 5GiB, 시스템 여유 1GiB 보호를 유지한다. 원본 정밀도가 현장 형태 유지 문제를 해결했다는 결과는 없었다.
- 프레임 전체 해독과 큰 밝기 변화·정지 구간·서서히 어두워지는 현상의 검토 표시. 검사 통과는 인물 수, 관절, 무게, 접촉이나 사실감의 검증을 뜻하지 않는다.

8개 프롬프트의 조건 파일을 실제로 계산했고, 재실행에서 모두 해시를 확인한 캐시를 재사용했다. 최종 두 CLIP 토크나이저로 검사한 가장 긴 입력은 특수 토큰 포함 65개로, 77개 제한 안에 들어간다. 검사 기록은 `D:\CursorVideoLocal\audits\site-prompt-token-budget.json`이다. 프롬프트 사전 준비는 텍스트 조건 계산을 줄이며 장비·사람의 동작을 새로 학습시키지 않는다.

## D에서 다시 준비할 때

준비된 D 폴더를 옮기는 경우 `datasets/construction-v1`도 함께 복사한다. 데이터 없이 실사 템플릿을 요청하면 다른 화면으로 자동 변경하지 않고 미준비 오류를 반환한다. 출처 사진 변경은 SHA256 검사에서 거절한다.

별도 설치에서는 D의 기본 Python으로 `tools/prepare_site_data.py`를 실행한다. 이 단계만 공개 원출처에 접속하고 고정된 파일·조건·해시를 확인한다. 이어 `tools/warm_site_prompts.py`가 오프라인으로 프롬프트 조건을 준비한다. 이 작업도 기존 영상과 동시에 모델을 띄우지 않으며 메모리 보호를 우회하지 않는다. 평상시 영상 생성은 계속 오프라인이다.

Cursor에서는 `D:\CursorVideoLocal\app`을 열고 프로젝트 `local-video` 연결을 다시 읽는다. 초안을 시험한 뒤 작업자 수·복장·몸 형태, 장비 관절·트랙·바퀴, 바닥 접촉, 이동 방향, 카메라, 조명과 자재 강성을 검토한다. 형태나 동작이 무너지는 결과를 사실감 검증에 성공했다고 표시하지 않는다.

## 최종 리빌드 검사

0.6.0의 자동 검사 94개, 스킬 형식, 실제 MCP 도구 6개의 연결 검사가 통과했다. 일반 현장 제작의 거절은 작업을 새로 만들지 않았고, 명시적인 현장 초안은 출처 표시와 사실감 미검증 표시를 반환했다. 모델 29개의 SHA256, 참고 원본 3개와 구간 9개의 해시·97프레임 전체 해독, 조건 파일 8개의 해시를 확인했다. 기록은 `D:\CursorVideoLocal\audits\site-final-0.6.0.json`이다. 실제 Cursor 화면과 LG 그램 실행은 검사하지 않았다.

설치본은 `D:\CursorVideoLocal\app`에 반영했고, 소스 리빌드 위치는 `D:\CursorVideoLocal\releases\LATEST.json`으로 찾는다. 리빌드 ZIP에는 코드·설명·검토한 초안과 출처가 들어가며 모델·실행 환경·참고 원본은 들어가지 않는다. 포터블 이동에는 D의 실행 폴더와 `datasets/construction-v1`, `cache/conditioning`을 함께 보존한다.
